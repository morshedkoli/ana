# 🎥 Influencer Studio — Content Creator Management & Studio Dashboard

[![Next.js](https://img.shields.io/badge/Platform-Web_Application-black?style=for-the-badge&logo=next.js)](https://nextjs.org/)
[![TypeScript](https://img.shields.io/badge/Language-TypeScript_|_JavaScript-blue?style=for-the-badge)](https://www.typescriptlang.org/)
[![License](https://img.shields.io/badge/License-MIT-green?style=for-the-badge)](LICENSE)

A dedicated digital workspace and content operations platform for video creators and digital influencers to schedule releases, review video drafts, and analyze audience engagement metrics.

---

## 🌟 Key Features

- **Video Release Scheduler**: Visual timeline for planning video launches across YouTube, TikTok, and Facebook.
- **Collaboration Workspace**: Manage video editors, scriptwriters, and thumbnail artists in a unified dashboard.
- **Engagement Analytics**: Track view counts, subscriber growth, and audience demographics.

---

## 🛠️ Technology Stack

- **Platform**: Next.js, React 19
- **Styling**: Tailwind CSS, Lucide Icons

---

## 🚀 Getting Started

```bash
# 1. Clone repository
git clone https://github.com/morshedkoli/influencerstudio.git

# 2. Install dependencies
npm install

# 3. Launch application
npm run dev
```
